---
title: Березовский поселок  
---

**Список для непричисленных крестьян, проживающих в поселениях Змеиногрский уезд Бухтарминская волость Березовский поселок**  

1.	Поликарп Иванов Кузнецов крестьянин Бухтарминской волости деревни Бочатареевой (Богатыревой) с 1898г  
2.	Терентий Васильев Манаров крестьянин Бухтарминской волости деревни Богатыревой с 1890г  
3.	Панкратий Васильев Макаров крестьянин Бухтарминской волости дер Богатыревой  
4.	Петр Фаддеев Щетников обыватель Зыряновской волости и села с 1892г  
5.	Ефим Петров Бородулин крестьянин Бухтарминской волости дер Тургусульской (Тургусунской) с 1894г
